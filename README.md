# 🏥 ClinicLink — Healthcare Appointment Management System

**ClinicLink** is a full-stack healthcare appointment management system designed to connect patients with doctors and simplify appointment management.

The platform provides separate interfaces for **Patients, Doctors, and Administrators**, making it easier to manage doctors, appointments, users, and payments from a centralized system.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Atanu-18/ClinicLink.git
```

### 2. Navigate into the Project

```bash
cd ClinicLink
```

### 3. Setup Frontend

```bash
cd Frontend
npm install
npm run dev
```

### 4. Setup Backend

Open a new terminal:

```bash
cd Backend
npm install
npm start
```

## 🎯 Project Goals

The main goals of ClinicLink are:

* Simplify doctor discovery and appointment booking.
* Provide doctors with an easy-to-use appointment management system.
* Give administrators centralized control over users, doctors, and appointments.
* Provide a secure online payment facility.
* Provide a responsive and user-friendly healthcare platform.
